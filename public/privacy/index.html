Конфиденциальность

Коротко: личные заметки, история и закладки остаются в вашем браузере. Необязательная статистика отправляется только после отдельного согласия.

Что хранится только на устройстве

TrafficLab использует локальное хранилище браузера для функций, которые работают лично для посетителя: истории просмотра, закладок, журнала тестов, заметок, выбранной темы, подсказок и других настроек интерфейса.

Текст заметок и содержимое журнала тестов не отправляются в базу TrafficLab. Если очистить данные сайта в браузере, эти записи могут быть потеряны.

Анонимная статистика

Просмотры страниц, глубина чтения, поисковые запросы внутри сайта и основные действия отправляются в собственный API TrafficLab только после выбора «Разрешить статистику».

Для подсчёта уникальных браузеров используется случайный локальный идентификатор. В базе он превращается в однодневный хеш, поэтому посещения одного браузера специально не связываются между разными днями.

Оценки статей

При нажатии 👍 или 👎 в базу передаются адрес статьи и выбранная оценка. Случайный идентификатор браузера используется только для того, чтобы один браузер имел одну текущую оценку на конкретную статью.

В базе TrafficLab не хранится открытый идентификатор браузера: перед записью голоса он хешируется вместе с адресом статьи.

Поисковые запросы

Если статистика разрешена, внутренний поисковый запрос может использоваться для понимания того, каких материалов не хватает. Перед сохранением система автоматически маскирует строки, похожие на email, URL, длинные номера и токены доступа.

Инфраструктура

Сайт планируется размещать через Cloudflare. Поставщик инфраструктуры может технически обрабатывать сетевые данные, необходимые для доставки и защиты сайта, в соответствии со своими условиями и политикой конфиденциальности.

Как изменить выбор

Выбор по анонимной статистике можно изменить в любой момент. Кнопка ниже заново откроет настройки конфиденциальности.

Связь

Если нужно сообщить о проблеме с данными или безопасностью сайта, используйте страницу «О проекте». До запуска отдельного канала поддержки TrafficLab не просит отправлять через сайт персональные документы или платёжные данные.
