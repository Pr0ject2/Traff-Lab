Подготовка

Как пользоваться редактором

1. Один раз подключить GitHub

Нажмите Подключение, укажите репозиторий и вставьте fine-grained token. Токен хранится только в sessionStorage текущей вкладки: переживает обновление страницы, но удаляется при выходе из админки или закрытии вкладки. В localStorage он не записывается.

2. Права токена

Достаточно доступа к одному репозиторию и разрешения Contents: Read and write. Не давайте токену лишних прав.

3. Публикация

Редактор коммитит изменения в выбранную ветку. Cloudflare Pages подключается к этой ветке GitHub и автоматически публикует изменения после коммита.

4. Аналитика Cloudflare

Создайте D1-базу и привяжите её к Pages-проекту под именем DB. Статистика читается только после входа в защищённую админ-сессию.

5. Защита редактора

/admin/ закрыт серверным паролем. Пароль хранится только в секрете Cloudflare ADMIN_PASSWORD, а сессия выдаётся через защищённую HttpOnly-cookie на 8 часов.
